# DeskRally project website

A static project overview and documentation site using the DeskRally road-rally identity.

Build with Python 3 using `python build.py`. Serve `dist/` with any static HTTP server. There are no third-party runtime libraries, analytics, external fonts, account forms, or live application integrations. Documentation search runs locally in the browser.

This private preview has indexing disabled. GitHub source links intentionally lead to a release-status page until a reviewed repository is public. Do not point visitors at a private repository or operational deployment.

Before public launch, review copy and assets, set the final public repository link, choose the appropriate licensing, enable indexing if desired, and configure the project domains. Domain routing and application hosting are separate concerns.
