# DeskRally product source

This repository is being prepared for the reviewed DeskRally product release. Its scope is the server services, agents and clients, self-hosted web console, deployment tooling and canonical technical documentation.

Application source migration is in progress. The current committed tree contains the release-preparation and licensing documents. Reviewed application batches will add their source, reproducible build instructions and required dependency notices.

The public project website has a separate source repository at https://github.com/Vaerchi/DeskRally-Website. Its public pages and introductory and technical guides are hosted at https://www.deskrally.com/docs/. The website publishes a reviewed documentation snapshot pinned to a product/development source revision, with the revision shown on each technical page.

Read RELEASE_PREPARATION.md for the remaining product-source work. Apache License 2.0 is selected for original project work. LICENSE, NOTICE and LICENSING.md cover the release's licensing and attribution preparation.
