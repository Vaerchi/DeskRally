# DeskRally

Remote support. A clearer route.

This repository is private while the reviewed public release is assembled. It starts with fresh history and an explicit file selection; the original development history is not imported.

## Included now

- `website/`: the project home, about page, five visitor guides, source-release status, and website privacy information.
- Original road-rally vector artwork without portraits or personal metadata.
- A dependency-free static-site generator and source assets.

Build the website with `python website/build.py`. The output is `website/dist/`.

## Application source migration

The application source has not yet been migrated into this repository. Website content and documentation are the first reviewed batch. See `RELEASE_PREPARATION.md` for the remaining work. This repository is not yet a complete application source release, and the website does not advertise a public installer or claim that a public source release is available.

Keep this repository private until the source, attribution, licensing, credentials, and final release artifact have been reviewed. No open-source license has been selected here yet.
